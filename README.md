# wearhats/homebrew-tap

Homebrew formulae for [hats](https://github.com/wearhats/hats).

```sh
brew install wearhats/tap/hats   # install
brew upgrade hats                # upgrade
brew uninstall hats              # uninstall
```

`Formula/hats.rb` is generated by the hats release workflow, which overwrites it on every release, so PRs editing it here get overwritten. To change the formula, change its template in the hats repository.

Report issues at [wearhats/hats](https://github.com/wearhats/hats/issues).
